# Simpler — Un campionatore facile.

Webapp progressiva (PWA) gratuita e offline-first per creare beat Boom Bap e Hip-Hop da smartphone e PC, pensata anche per workshop in classe (0 € / HTTPS / 0 latenza di rete).

## Funzionalità principali
- **SAMPLE**: 4 banchi (A–D) × 16 pad multi-touch a bassissima latenza, Hold-to-Record dal microfono direttamente sui pad vuoti, Resampling interno lossless, import di file audio e video registrazioni schermo (es. YouTube), Waveform Editor con pinch-to-zoom, Trim, Auto-Chop (Transients, Equal, Lazy) e Keyboard Mode a scale.
- **Boom Bap Starter Kit integrato**: 16 suoni 90s Hip-Hop (kick, snare, hat, vinyl dust, jazz chops, upright bass, soul brass, vibes, scratch) sintetizzati proceduralmente al volo (~0 KB di download).
- **SEQUENCE**: Registrazione live in overdub con Count-in 1-2-3-4, Metronomo, Quantize, Swing Boom Bap, Song Mode, Piano Roll visivo con Velocity ed Export offline in **WAV** e **Stems .ZIP**.
- **Modalità Workshop**: QR Code generato localmente a schermo intero + PWA offline-first.

## Sviluppo locale
```bash
npm install
npm run dev
```
